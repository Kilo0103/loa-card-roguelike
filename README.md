# LOA Card Roguelike

로스트아크의 전투 요소를 카드게임 규칙으로 재해석하는 싱글 플레이 덱빌딩 로그라이크 프로젝트입니다.

## 개발 원칙
- 기존 `loa-homework` 및 다른 프로젝트와 분리
- 작은 Vertical Slice부터 검증
- 카드 데이터와 전투 로직 분리
- 기능 단위 브랜치로 개발

## 첫 Vertical Slice
새 런 → 시작 덱 → 단일 적 전투 → 승리 → 카드 3장 중 1장 선택/스킵 → 다음 전투

초기 전투 핵심:
- HP
- 행동력
- 드로우 / 손패 / 버림 더미
- 적 의도
- 실드
- 무력화
